# 挂件组件与控件规范

保留银狼人物、白色云朵和紫色强调色；设置采用紧凑浮层。以下尺寸以 100% 挂件缩放为准，人物缩放范围仍为 60%–160%。

## 尺寸与样式

| 项目 | 规范 |
| --- | --- |
| 正文 / 辅助文字 / 浮层标题 | 12 / 11 / 14px |
| 按钮、输入框高度 | 28px |
| 图标按钮 / 图标 | 26 / 18px |
| 间距 | 4px 基准，组内 4–8px，组间 12px |
| 控件 / 浮层圆角 | 6 / 12px |
| 设置浮层 | 宽 304px、内边距 12px、最大高 360px，内容内部滚动 |
| 数值与路径 | 等宽字体、表格数字；长路径截断但 title 保留全文 |

共享变量和 `.ui-button`、`.ui-input`、`.ui-icon-button`、`.ui-form-row`、`.ui-help`、`.ui-error` 位于前端全局样式中。当前使用浅色主题，不提供主题切换。云朵轮廓、额度大数字和人物动效属于专用视觉，不强制套用表单尺寸。

- 悬停使用浅紫背景；选中同时使用描边与 aria-pressed，不只靠文字颜色。
- 键盘焦点有清晰轮廓；禁用控件降低透明度并禁止提交；错误在对应输入附近说明。
- 图标按钮提供中文名称；输入使用关联标签；减少动态效果偏好下停用旋转、过渡与回弹。
- 预设立即保存；路径、自定义秒数通过 Enter 或保存按钮提交。保存失败显示错误，不假装已保存。

## 组件职责

| 组件或逻辑 | 职责与接口 |
| --- | --- |
| DesktopWidget | 组合人物、额度、工具栏、设置；协调持久化与原生点击区域 |
| SettingsPopover | 对话框容器、Tab 循环、Esc/关闭按钮、恢复焦点；接收 restoreFocus，发出 close |
| WidgetSettings | 接收 preferences、saving；维护草稿，发出 save(patch)、scale(delta) |
| WidgetActions | 人物旁工具栏及左右切换；提供额度、刷新、设置、收起入口 |
| QuotaBubble | 接收 snapshot、error、loading、now，仅展示额度或错误/空态 |
| useQuotaDismiss / quotaDismiss | 管理交互保护与可取消的计时；不请求额度、不保存设置 |
| useUsage / usageState | 定时刷新与可测试的请求状态；拒绝过期连接响应 |

设置浮层位于画布左上 (24, 24)，在回弹容器之外，随挂件缩放但不压扁。打开时底层挂件设为 inert，不添加覆盖整个画布的遮罩。原生区域包含人物、工具栏、展开的气泡及设置；设置区域额外预留 12px 阴影/焦点范围，关闭后立即释放。

## 时长与刷新

`Preferences.quotaDismissSeconds` 为整数 1–3600 或 null（常驻），默认 1。旧配置自动补默认值，损坏的时长字段单独恢复，其他有效设置保留。常驻仅表示展开后不自动收起，不表示开机自动展开。

- 展开后计时。加载、鼠标停留在气泡或操作栏、键盘操作气泡或操作栏、设置打开期间暂停；全部解除后重新完整计时。
- 点击人物只展开额度；已展开时再次点击保持显示并重新完整计时。手动收起使用工具栏的收起按钮，拖动后的点击不会触发展开。
- 鼠标点击残留的普通焦点不暂停。按 Esc 关闭设置并回到工具栏的键盘焦点仍受到保护。
- 关闭、卸载、改变时长都取消旧回调；后台刷新不主动展开气泡。
- 刷新期间保留旧快照及更新时间，底部增加小型 loading 与「更新中」；成功时替换数据和更新时间。
- 首次无数据时保留空态；失败清除旧快照并显示错误；切换 CLI 路径立即清除旧连接数据。

## 验证基线

Node 测试覆盖计时、交互暂停、常驻、清理、快照保留、失败恢复、连接竞态及浮层几何。Rust 测试覆盖默认值、范围验证、旧配置兼容、单字段修复与保存/读取。浏览器及 Windows 验收结果和未覆盖项见 [windows-validation.md](windows-validation.md)。
